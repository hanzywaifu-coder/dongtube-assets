# @hanzywaifu/assets

Assets for Dongtube API - fonts, images, and templates.

## Installation

```bash
npm install @hanzywaifu/assets
```

## Usage

```javascript
const assets = require('@hanzywaifu/assets');

// Get font
const font = assets.font.get('THEBOLDFONT');

// Get image
const image = assets.image.get('WELCOME');
```
